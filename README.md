# lanternbook

A personal project for me and my friends: a local-first character companion for a D&D 5e table. For now it covers two characters, a Circle of the Moon druid and an Artillerist artificer. It is a successor to an earlier private app of mine.

This repository currently holds only the project skeleton and CI. There is no app code yet.

## Unofficial

lanternbook is an unofficial fan project. It is not affiliated with, endorsed by, or sponsored by Wizards of the Coast.
