## Generalize first

- `setup.sh`: loop over every tool in `tool-versions.env` instead of hard-coding gitleaks, and support arm64 and macOS or fail with the same message.
- `check-hooks.mjs`: read the stage list from one place shared with `.husky/pre-commit`, so adding a stage does not mean editing both.
- The fails-on-empty scripts: separate the "refuse to pass on zero inputs" rule from each tool's output parsing, so another tool can be added without copying a script.
- `check-ca-scripts.mjs`: split the `setup.sh` scenario from the install-script scenarios so either half can move on its own.
- `docs/VERIFICATION.md` and `docs/REPO-SETTINGS.md`: move the repo-specific job list, run link and dates out of the generic text.
